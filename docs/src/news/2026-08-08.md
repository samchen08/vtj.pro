## 什么是 VTJ.PRO？

先快速回顾一下：VTJ.PRO 是一款开源的 AI 低代码引擎，基于 Vite + Vue 3 + TypeScript 构建。它的核心理念是 **“生成代码即源码”**——通过 DSL（领域特定语言）与 Vue 3 源码的双向转换，让**可视化设计**和**工程化开发**真正融为一体。

而今天的主角——**v2.6.1 的 Agent 系统**，正是这一理念在 AI 领域的深度延伸：AI 的产出不再是一段孤立的代码片段，而是**结构化的、可追溯的、可继续可视化编辑的工程资产**。

## 双代理架构：让 AI 既“会思考”又“会动手”

传统 AI 编程助手常常“边想边做”，规划时掺入执行细节，执行时又丢失全局视野，最终产出不够可靠。

VTJ.PRO v2.6.1 采用 **“双代理”（Dual-Agent）架构**，把思考和执行彻底分开：

- **Architect（架构师）**：负责理解你的需求，拆解成清晰的任务步骤，输出结构化的执行计划（JSON 格式），告诉系统“**做什么、按什么顺序做**”。
- **Editor（执行者）**：严格按照计划逐步执行，通过“推理→行动→观察→再推理”的循环（ReAct 模式），调用各种设计器工具、生成和修复代码，并用 `refresh` 工具做**运行时验证**，确保代码真的能跑通。

两套角色的上下文相互隔离，各司其职，避免了“角色错乱”和“抢跑”问题。

> 此外，系统还保留了 **single（单代理）** 模式，兼容传统的一问一答式代码生成，满足轻量场景需求。

## 40+ 内置工具，自然语言直控工程全流程

新 Agent 内置了超过 40 个贴近真实开发场景的专业工具，覆盖：

- 页面增删改、区块管理
- API 配置、依赖管理
- 全局样式、Pinia 状态管理
- 权限插件、Axios 拦截器、路由守卫
- i18n 国际化、环境变量
- ……

所有工具都采用**声明式定义**（名称、描述、参数规范、风险等级），运行时统一注册。

更重要的是，系统对工具调用实施了**三级风险管控**：

| 风险等级                  | 说明                 | 处理方式                 |
| ------------------------- | -------------------- | ------------------------ |
| **readonly（只读）**      | 如查询页面列表       | 直接执行，无需审批       |
| **write（写操作）**       | 如创建页面、修改配置 | 弹窗提示，需用户确认     |
| **destructive（删除类）** | 如删除页面、移除 API | 弹窗警示，需用户二次确认 |

你可以一键开启“全部批准”来加速批量任务，也能随时关闭，把高风险操作牢牢握在自己手中。所有审批记录都会落库，形成完整的**审计链条**。

## ReAct 验证闭环：让生成的代码“真的能跑”

AI 写的代码“看起来对，一跑就错”是行业通病。VTJ.PRO v2.6.1 用 **ReAct 多轮循环 + refresh 验证** 构建了质量闭环：

1. 在每个执行步骤中，模型可以多次“思考→行动”。
2. 生成的 Vue 源码会经过 `parseVue` 编译为 DSL，再通过引擎原子性地落入项目模型——设计器画布、代码编辑器、项目文件**三者实时同步**。
3. 最关键的 **`refresh` 工具**会触发设计器模拟器刷新，并**自动捕获运行时错误**。
4. 一旦发现报错，系统立即把源码和错误信息回灌给模型，驱动它继续修复，直到验证通过。

这套机制让 AI 的产出从“代码片段”升级为“**经过运行时验证的可交付资产**”。

## 上下文工程：把 token 消耗从 O(n²) 压到近似 O(1)

多步骤 Agent 面临的最大挑战是**上下文长度随步骤数爆炸式增长**——步骤越多，单次调用的 token 越大，成本也越高。

VTJ.PRO v2.6.1 用**三级策略**系统性地解决了这个难题：

- **P0 预算裁剪**：设置 20K token 的上下文预算，最近 6 条对话全量保留，历史信息按价值从低到高裁剪。
- **P1 增量摘要**：每完成 5 个步骤，异步调用 LLM 将窗口外的历史压缩成进度摘要并缓存，后续请求用摘要替代原始消息，大幅压缩上下文。
- **P2 多级内存缓存**：对话查询结果和展开后的消息片段都按内容指纹缓存，LRU 自动淘汰，减少重复计算。

这套组合拳让系统在长任务中始终保持稳定的 token 消耗，调用成本显著降低。

---

## 断点恢复 + 最小粒度重试，长任务“可续可查”

AI 辅助开发的长任务（比如“从零构建一个完整的管理后台”）可能涉及几十个步骤，中途网络波动、浏览器刷新、意外中断都可能导致前功尽弃。

VTJ.PRO v2.6.1 设计了**三级粒度的断点恢复机制**：

- **规划阶段取消**：复用规划 ID 重新生成计划。
- **步骤执行中取消**：标记中断点，从断点步骤续跑，已完成的步骤自动跳过。
- **总结阶段取消**：仅重新生成任务总结。

此外，你可以**重试任意轮次的任意失败步骤**，不再局限于“最后一轮重来”。后端在中断时还会自动补录 trace 记录（包含计划、步骤状态、token 消耗、耗时等），让每个任务都有“终态记录”可查。

## 多模态输入：设计稿秒变代码

v2.6.1 支持**图片识别**和**设计稿 JSON 导入**两种多模态输入：

- **图片识别**：调用多模态模型对 UI 设计图进行结构化分析，自动生成页面搭建提示词。
- **设计稿 JSON**：自动识别 Sketch、Figma、MasterGo 等主流工具的导出数据，转译为可执行的页面还原指令。

你只需上传一张设计稿截图或导出 JSON，AI 就能在 1 分钟内生成高度还原的 Vue 3 组件代码骨架，极大缩短从设计到代码的链路。

## 模型无关，自由切换 LLM 后端

VTJ.PRO 的 AI 子系统基于 OpenAI 兼容协议统一封装，支持 OpenAI、Azure、Anthropic、Google、DeepSeek、智谱、百度、阿里、腾讯及任意自定义端点。多个 API Key 可轮询使用，实现负载均衡和容灾。你也可以用自己的 Key 调用自定义模型，不消耗平台额度。

系统还为不同角色（Architect / Editor / 多模态）配置了专用模型路由，让“专业模型做专业事”。
